# LocalTag

Mp3tag 스타일의 오프라인 음악 태그 편집기 (macOS, Python + PySide6 + mutagen).

## 실행

    ./run.sh                 # 빈 창으로 시작
    ./run.sh ~/Music/앨범폴더  # 폴더를 열면서 시작

## 앱(.app)으로 만들기

    ./build_app.sh           # → dist/LocalTag.app

만든 `LocalTag.app`을 `응용 프로그램` 폴더로 옮기면 Launchpad·Spotlight에서 실행할 수 있습니다.
Dock 아이콘에 음악 파일이나 폴더를 끌어다 놓으면 목록에 추가됩니다.

## 1단계 기능

- 지원 형식: MP3, FLAC, OGG, Opus, M4A/MP4, WMA, WAV, AIFF, APE, WavPack, MPC, TTA, DSF
- 폴더 열기/추가, 파일 추가, 창에 끌어다 놓기, 하위 폴더 포함 옵션
- 파일 목록: 열 정렬, 열 순서 이동, 헤더 우클릭으로 열 표시/숨김 (창 크기·열 배치 기억)
- 태그 패널: 제목, 아티스트, 앨범, 앨범 아티스트, 연도, 트랙, 디스크, 장르, 작곡가, 코멘트, 파일명
- 여러 파일 동시 편집: 값이 다르면 `< 유지 >`, `< 비우기 >`로 지우기, 바꾼 필드만 저장
- 여러 값은 `\\`로 구분 (예: `가수A\\가수B`)
- 커버: 추가(파일 선택/끌어다 놓기/클립보드 붙여넣기), 삭제, 이미지로 내보내기, 클립보드로 복사
- 태그 제거, 재생(기본 앱), Finder에서 보기
- 설정: ID3v2.3/v2.4, ID3v1 함께 쓰기, 옛 한글(CP949) 태그 자동 인식, 수정 시각 유지

## 2단계 기능: 변환기와 포맷 문자열

변환 메뉴(또는 목록 우클릭 → 변환)에서 선택한 파일에 적용합니다. 모든 변환기는 미리보기를 보여 주고, 오류나 이름 충돌이 있는 파일은 건너뜁니다.

| 변환기 | 단축키 | 예 |
|---|---|---|
| 태그 → 파일명 | ⌥1 | `$num(%track%,2) %title%` · `%artist%/%album%/%title%` (폴더 생성) |
| 파일명 → 태그 | ⌥2 | `%track% - %artist% - %title%` · `%dummy%` 로 건너뛰기 |
| 파일명 → 파일명 | ⌥3 | `%1 - %2` → `%2 - %1` |
| 텍스트 → 태그 | ⌥4 | 곡 목록을 붙여 넣고 `%track%. %title%` |
| 태그 → 태그 | ⌥5 | 제목 필드에 `$caps(%title%)` |

- 포맷 문법: `%field%`, `$함수(…)`, `[조건부 구간]`, `'그대로 출력'`
- 함수 50여 개: `$if $if2 $if3 $ifgreater $eql $left $right $mid $num $caps $replace $regexp $meta …`
- 특수 필드: `%_filename% %_directory% %_counter% %_length% %_bitrate%` 등
- 전체 목록은 변환 대화상자의 **도움말** 버튼에 있습니다.
- 입력한 포맷 문자열은 기록되어 다음에 다시 고를 수 있습니다.

## 3단계 기능: 액션, 필터, 자동 번호, 실행 취소

- **액션 그룹** (액션 → 액션 그룹…, ⌥6): 여러 액션을 묶어 저장하고 한 번에 실행합니다. 실행 전에 바뀌는 내용을 미리 보여 줍니다.
  - 액션 종류: 바꾸기, 정규식 바꾸기, 대소문자 변환(예외 단어 지정), 값 포맷(파일명 포함), 필드 제거, 선택한 필드만 남기기, 여러 값 나누기·합치기, 값 추측, 파일에서 커버 가져오기, 커버를 파일로 내보내기, 커버 제거
  - 기본 예제 그룹 5개가 들어 있습니다. 그룹은 `~/Library/Application Support/LocalTag/actions.json`에 저장됩니다.
- **빠른 액션** (⌥7): 그룹에 저장하지 않고 액션 하나를 바로 실행합니다.
- **자동 번호 매기기** (⌘K): 목록 순서대로 트랙 번호를 매깁니다. 시작 번호, 자릿수, 전체 곡 수, 폴더별로 다시 시작, 디스크 번호 옵션이 있습니다.
- **필터** (⌘F, Esc로 지우기): 목록 위 입력칸에 조건을 입력합니다.
  - 그냥 단어: 파일명과 모든 필드에서 찾기 (예: `아이유 봄`)
  - `artist HAS 아이유`, `album IS "꽃갈피"`, `title MATCHES "^\d+"`, `year GREATER 2010`, `genre MISSING`, `comment PRESENT`
  - `NOT`, `AND`, `OR`, 괄호로 조합. 포맷 문자열도 가능 (`$len(%title%) GREATER 30`)
- **실행 취소** (⌘Z): 저장, 변환, 액션, 자동 번호, 태그 제거를 작업 단위로 되돌립니다. 이 프로그램이 편집하지 않는 필드까지 포함해 태그 전체, 파일 이름, 수정 시각을 원래대로 돌려놓습니다. 최근 30개 작업까지 기억하며, 앱을 끄면 기록이 사라집니다.

## 4단계 기능: 확장 태그, 내보내기, 재생목록

- **확장 태그** (편집 → 확장 태그…, ⌘T): 파일의 모든 필드를 보고 추가·수정·삭제합니다.
  - `LYRICIST`, `MOOD`, `BPM`, `UNSYNCEDLYRICS`(가사), `CATALOGNUMBER` 같은 사용자 정의 필드도 됩니다.
  - 형식마다 알맞은 저장 방식으로 씁니다. ID3는 전용 프레임 또는 TXXX, MP4는 전용 아톰 또는 iTunes 사용자 정의 필드, FLAC·OGG·APE·WMA는 필드 이름 그대로입니다.
  - 여러 커버를 관리합니다: 추가, 삭제, 내보내기, 종류(앞 표지, 뒷 표지 등)와 설명 지정
  - 여러 파일을 선택하면 값이 다른 필드는 `< 유지 >`로 표시되고, 바꾼 필드만 씁니다.
- 확장 필드는 포맷 문자열(`%lyricist%`), 변환기, 액션, 필터에서도 씁니다. 필드 선택칸에 이름을 직접 입력하면 됩니다.
- **내보내기** (⌘E): CSV(엑셀용, 한글 깨짐 방지), HTML(표 웹 페이지), 텍스트. 열과 줄은 포맷 문자열로 정합니다.
- **재생목록 만들기** (⌘L): 선택한 파일을 목록 순서대로 M3U8로 저장합니다. 상대 경로와 곡 정보(#EXTINF) 옵션이 있습니다.
