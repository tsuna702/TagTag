# LocalTag

Mp3tag 스타일의 음악 태그 편집기 (macOS, Python + PySide6 + mutagen).
앨범아트 검색·YouTube 썸네일 말고는 인터넷을 쓰지 않으며, 그 기능도 버튼을 눌렀을 때만 연결합니다.

## 실행

    ./run.sh                 # 빈 창으로 시작
    ./run.sh ~/Music/앨범폴더  # 폴더를 열면서 시작

## 앱(.app)으로 만들기

    ./build_app.sh           # → dist/LocalTag.app

만든 `LocalTag.app`을 `응용 프로그램` 폴더로 옮기면 Launchpad·Spotlight에서 실행할 수 있습니다.
Dock 아이콘에 음악 파일이나 폴더를 끌어다 놓으면 목록에 추가됩니다.

## 1단계 기능

- 지원 형식: MP3, FLAC, OGG, Opus, M4A/MP4, WMA, WAV, AIFF, APE, WavPack, MPC, TTA, DSF
- 폴더 열기/추가, 파일 추가, 창에 끌어다 놓기, 하위 폴더 포함 옵션
- **최근 연 폴더** (파일 → 최근 연 폴더, ⌥⌘1~9): 최근 10개. ⇧ 를 누른 채 고르면 지금 목록에 추가합니다. 없어진 폴더는 흐리게 보입니다.
- **시작할 때 마지막 목록 다시 열기** (파일 메뉴, 기본 꺼짐): 켜 두면 앱을 다시 켤 때 지난번 목록을 그대로 불러옵니다.
- 파일 목록: 열 정렬, 열 순서 이동, 헤더 우클릭으로 열 표시/숨김 (창 크기·열 배치 기억)
- 태그 패널: 제목, 아티스트, 앨범, 앨범 아티스트, 연도, 트랙, 디스크, 장르, 작곡가, 코멘트, 파일명
- 여러 파일 동시 편집: 값이 다르면 `< 유지 >`, `< 비우기 >`로 지우기, 바꾼 필드만 저장
- 여러 값은 `\\`로 구분 (예: `가수A\\가수B`)
- 커버: 추가(파일 선택/끌어다 놓기/클립보드 붙여넣기), 삭제, 이미지로 내보내기, 클립보드로 복사
- 태그 제거, 재생(기본 앱), Finder에서 보기
- 설정: ID3v2.3/v2.4, ID3v1 함께 쓰기, 옛 한글(CP949) 태그 자동 인식, 수정 시각 유지

## 2단계 기능: 변환기와 포맷 문자열

변환 메뉴(또는 목록 우클릭 → 변환)에서 선택한 파일에 적용합니다. 모든 변환기는 미리보기를 보여 주고, 오류나 이름 충돌이 있는 파일은 건너뜁니다.

| 변환기 | 단축키 | 예 |
|---|---|---|
| 태그 → 파일명 | ⌥1 | `$num(%track%,2) %title%` · `%artist%/%album%/%title%` (폴더 생성) |
| 파일명 → 태그 | ⌥2 | `%track% - %artist% - %title%` · `%dummy%` 로 건너뛰기 |
| 파일명 → 파일명 | ⌥3 | `%1 - %2` → `%2 - %1` |
| 텍스트 → 태그 | ⌥4 | 곡 목록을 붙여 넣고 `%track%. %title%` |
| 태그 → 태그 | ⌥5 | 제목 필드에 `$caps(%title%)` |

- **곡명 · 파일명 일괄 변경** (변환 → 곡명 · 파일명 일괄 변경…, ⌥9, 도구 막대 **일괄 변경…**): 파일 이름 일괄 변경 프로그램처럼 규칙을 쌓아 위에서부터 차례로 적용합니다. 고른 곡, 고른 곡이 없으면 목록에 보이는 곡 전체. 바꾸기 규칙에는 **자주 쓰는 정규식** 단추(괄호·대괄호·【】 지우기, 앞 번호 지우기, feat. 지우기, '아티스트 - 제목' 나누기·뒤바꾸기, 영상 꼬리말 지우기 등 — 고르면 찾을 말·바꿀 말을 채우고 정규식을 켬)와 **?** 단추(정규식 쓰는 법 표)가 있습니다.
  - 바꿀 곳: 제목, 파일명(확장자 빼고), 앨범, 아티스트 등 아무 필드. 제목이 비어 있으면 파일명에서 시작할 수 있습니다.
  - 규칙: 바꾸기(정규식 가능, `$1`), 앞·뒤에 붙이기, 끼워 넣기(몇 글자 다음, 뒤에서부터), 글자 지우기(앞에서 N · 뒤에서 N · M번째부터 N · 찾을 말 앞쪽/뒤쪽), 번호 붙이기(시작·증가·자릿수), 대소문자, 공백 정리, 전각 ↔ 반각, 새 이름(포맷 문자열, `%_value%` = 지금까지 바뀐 이름).
  - 규칙을 고르면 오른쪽에서 설정을 바꾸고, 미리 보기는 바로 바뀝니다. 체크를 끄면 건너뛰고, ↑ ↓ 로 순서, 복제.
  - **규칙 묶음**: 이름을 붙여 저장해 두고 다시 고릅니다. 마지막에 쓴 규칙은 다음에 열 때 그대로 있습니다.
  - 이름이 겹치는 파일은 미리 보기에서 오류로 표시하고 건너뜁니다. ⌘Z 로 한꺼번에 되돌립니다.
- **형식 변환** (변환 메뉴): FLAC·WAV·AIFF 같은 무손실 파일을 **ALAC**(무손실 .m4a)로, 또는 어떤 파일이든 **AAC** 256·320kbps 로 바꿉니다. Music 이 못 읽는 FLAC 을 넣을 때 씁니다. macOS 는 들어 있는 afconvert, **Windows 는 ffmpeg**(없으면 설치 방법 `winget install Gyan.FFmpeg` 을 알려 줌, 설치 뒤 앱을 다시 켜지 않아도 됨)를 쓰고(비트 깊이 그대로, Windows 는 OGG·Opus·APE·WMA 등도 읽음), 태그와 커버를 옮기고, 길이가 같은지 확인합니다. 새 파일은 같은 폴더에 만들고 목록에 넣으며, 'Music 보관함에 추가'(macOS, 기본 켬)를 켜 두면 Music 에도 바로 넣습니다. 원본은 그대로 두거나 휴지통으로 옮깁니다. 실행 취소로 되돌릴 수 없는 작업이라 변환 전에 한 번 더 묻습니다. 손실 파일 → ALAC 처럼 의미 없는 변환은 건너뜁니다. 새 파일을 만드는 작업이라 실행 취소에는 들어가지 않습니다.
- **Apple Music · MusicBrainz 에서 태그 가져오기** (변환 메뉴, ⇧⌘G): 고른 곡의 앨범을 Apple Music 에서 검색해(앨범 링크도 됨) 곡 목록을 받아 옵니다. 제목·트랙 번호·길이가 비슷한 곡끼리 자동으로 짝짓고, **곡마다 '짝지은 곡' 칸에서 직접 고를 수 있습니다**. 순서대로 짝짓기·짝 모두 풀기, 자신 없는 짝·겹친 짝은 주황색. 곡 표는 처음에 디스크·트랙 번호 오름차순이고, 머리글을 누르면 그 칸으로 정렬합니다(한 번 더 누르면 내림차순, 짝은 곡을 따라감). **적용** 을 누르면 몇 곡에 무엇을 넣는지 한 번 더 묻습니다. 넣을 정보(제목, 아티스트, 앨범, 앨범 아티스트, 연도, 장르, 트랙·디스크 번호와 총수, **작곡가, 저작권, 레이블, ISRC, 바코드(UPC), 컴필레이션**, 연도 칸에 발매일 전체, 커버 600~3000px, 모두 선택·모두 해제)를 골라 적용합니다. 작곡가 등은 Apple Music 카탈로그에서 받고(곡 표의 '작곡가' 칸에 미리 보임), MusicBrainz 는 ISRC·레이블·바코드를 줍니다. 고른 앨범의 커버를 미리 보여 줍니다. 한국 스토어에 없으면 일본·미국 스토어에서 찾습니다. 키가 필요 없는 iTunes 공개 API 를 씁니다. **MusicBrainz 로 보충**: 'MusicBrainz'를 켜 두면(기본) Apple Music 결과 뒤에 MusicBrainz 결과를 붙이고, 검색어와 앨범 이름이 거의 같은 것은 출처에 상관없이 맨 위로 올립니다 — 애니·게임 OST 처럼 Apple Music 에 없는 앨범용. MusicBrainz 발매 링크·MBID 를 넣어도 됩니다. 커버는 Cover Art Archive 에서(500·1200px·원본). MusicBrainz 앨범에 커버가 없으면 같은 앨범의 다른 판, 그래도 없으면 Apple Music 에서 이름이 거의 같은 앨범의 커버를 빌려 오고 어디서 왔는지 앨범 이름 옆에 보여 줍니다. 검색 결과는 앨범·아티스트·연도·곡 수·나라·출처 표로, 머리글을 눌러 정렬합니다.
- 포맷 문법: `%field%`, `$함수(…)`, `[조건부 구간]`, `'그대로 출력'`
- 함수 50여 개: `$if $if2 $if3 $ifgreater $eql $left $right $mid $num $caps $replace $regexp $meta …`
- 특수 필드: `%_filename% %_directory% %_counter% %_length% %_bitrate%` 등 (`%_codec%` 은 실제 코덱 AAC·ALAC·FLAC·MP3, `%_bitspersample% %_lossless% %_quality% %_has_cover%`)
- **쓸 수 없는 문자** (태그 → 파일명, 파일명 → 파일명): 값 속의 `/ \ :` 를 밑줄(`AC_DC`), 비슷한 전각 문자(`AC／DC`), 지우기(`ACDC`) 중에서 고릅니다. Windows 문자(`* ? " < > |`)도 바꾸기를 켜면 같은 방식으로 바뀝니다.
- 전체 목록은 변환 대화상자의 **도움말** 버튼에 있습니다.
- 입력한 포맷 문자열은 기록되어 다음에 다시 고를 수 있습니다.

## 3단계 기능: 액션, 필터, 자동 번호, 실행 취소

- **액션 그룹** (액션 → 액션 그룹…, ⌥6): 여러 액션을 묶어 저장하고 한 번에 실행합니다. 실행 전에 바뀌는 내용을 미리 보여 줍니다.
  - 액션 종류: 바꾸기, 정규식 바꾸기, 대소문자 변환(예외 단어 지정), 값 포맷(파일명 포함), 필드 제거, 선택한 필드만 남기기, 여러 값 나누기·합치기, 값 추측, 파일에서 커버 가져오기, 커버를 파일로 내보내기, 커버 제거
  - 기본 예제 그룹 5개가 들어 있습니다. 그룹은 `~/Library/Application Support/LocalTag/actions.json`에 저장됩니다.
- **빠른 액션** (⌥7): 그룹에 저장하지 않고 액션 하나를 바로 실행합니다.
- **자동 번호 매기기** (⌘K): 목록 순서대로 트랙 번호를 매깁니다. 시작 번호, 자릿수, 전체 곡 수(원래 있던 총수 그대로 · 묶음의 곡 수로 · 넣지 않기), 폴더별로 다시 시작, 디스크 번호 옵션이 있습니다. 창 안에서도 곡을 골라 ↑ 위로 / ↓ 아래로(⌥⌘↑ / ⌥⌘↓) 옮기면 번호가 바로 다시 매겨지고, 번호를 매기면 목록 순서도 그대로 바뀝니다.
- **트랙·디스크 번호 / 총수**: 태그 패널에서 번호와 총수를 따로 고칩니다. 여러 곡을 골라 총수만 넣으면 곡마다 번호는 그대로 두고 총수만 바뀝니다 (예: 1/12, 2/12 …). 번호 칸을 < 유지 >로 두면 곡마다 그대로입니다.
- **YouTube 업로드 순서로 번호 매기기** (액션 메뉴 · 도구 막대 '업로드 순서 번호' · '연도별 디스크 번호'): YouTube 에서 받은 곡을 채널·재생목록에 올라온 순서대로 번호를 매깁니다. 방식은 두 가지 — **① 한 줄로 이어서** 모든 곡에 1, 2, 3 … 끝까지(디스크 번호는 지우거나 그대로), **② 연도마다 디스크** 2018 → 디스크 1, 2019 → 디스크 2 … 를 매기고 그 안에서 1, 2, 3 …. 창 위에서 바꿀 수 있고 마지막 방식을 기억합니다. 채널 주소(@이름)나 재생목록 주소를 넣고 **불러오기** 를 누르면 영상 목록을 받아 곡과 짝짓습니다 — 제목에서 【】·[]·() 속 군더더기와 ' / Eurobeat Remix' 같은 채널 꼬리말을 빼고 비교하고, 길이도 봅니다. 파일 이름의 [영상ID](yt-dlp 기본 이름)나 태그 안의 YouTube 주소가 있으면 그 영상을 그대로 씁니다. 짝은 곡마다 고칠 수 있고, 확실하지 않은 짝은 주황색입니다. 업로드 칸에 날짜(2019-08-14)나 영상 링크를 직접 넣을 수도 있습니다(채널 목록에 없는 영상). 올라온 날짜·시각(이 컴퓨터의 시간대) 순서로 번호를 매기고, 트랙 번호는 3/42 또는 3, 날짜 없는 곡은 그대로 두거나 맨 뒤로, 연도 칸에 업로드 연도를 넣을지 고릅니다. 바뀌는 칸은 굵게 보이고, 적용하면 실행 취소할 수 있습니다. API 키는 필요 없습니다.
- **목록 순서 바꾸기** (끌어다 놓기, 또는 ↑ 위로 ⌥⌘↑ / ↓ 아래로 ⌥⌘↓): 선택한 곡을 끌어다 원하는 위치에 놓거나 한 칸씩 옮깁니다. 자동 번호 매기기 창의 표에서도 똑같이 됩니다. 열 정렬은 풀리고 직접 정한 순서가 됩니다 (필터를 쓰는 중에는 옮길 수 없음). 도구 막대의 **트랙 번호…** 로 이 순서대로 번호를 매깁니다 — 선택한 곡, 선택이 없으면 목록 전체.
- **필터** (⌘F, Esc로 지우기): 목록 위 입력칸에 조건을 입력합니다. 그냥 단어로 찾을 때는 옆의 칸에서 **찾을 곳**(모든 필드 · 제목·파일명 · 아티스트 · 앨범)을 고릅니다 — 예: 앨범 이름에 든 단어로 다른 곡까지 걸리지 않게 '제목 · 파일명'.
  - 그냥 단어: 파일명과 모든 필드에서 찾기 (예: `아이유 봄`)
  - `artist HAS 아이유`, `album IS "꽃갈피"`, `title MATCHES "^\d+"`, `year GREATER 2010`, `genre MISSING`, `comment PRESENT`
  - `NOT`, `AND`, `OR`, 괄호로 조합. 포맷 문자열도 가능 (`$len(%title%) GREATER 30`)
  - 음질·커버: `cover MISSING`, `lossless PRESENT`, `bitrate LESS 192`, `codec IS AAC`, `samplerate`, `bits`, `quality`
  - **빠른 필터** (입력칸 옆 버튼): 커버 없는 곡, 낮은 음질(192 kbps 미만), 손실 압축, 무손실, AAC 만, 제목·아티스트·앨범·트랙 번호 없음. **커버 없는 곡을 모두 골라 커버 짝짓기…** 로 바로 커버 짝짓기 창을 엽니다.
- **정렬용 이름 열** (헤더 우클릭): 정렬용 제목·아티스트·앨범·앨범 아티스트. Music 은 이 값으로 정렬합니다 (예: `米津玄師` → `Yonezu Kenshi`). 목록 칸에서 바로 고치고(더블클릭·F2), 곡명 · 파일명 일괄 변경의 대상으로도 고를 수 있습니다. ID3v2.3 으로 저장해도 Music 이 읽는 정렬 프레임(TSOP 등)으로 씁니다.
- **음질 열** (헤더 우클릭): 코덱(AAC·ALAC·FLAC·MP3 — 확장자가 아니라 실제 내용), 비트 깊이, 음질(무손실 · 고음질 256 kbps 이상 · 보통 · 낮음 192 kbps 미만).
- **YouTube 제목 정리** (액션 → YouTube 제목 정리…, ⌥8): 고른 곡(없으면 목록에 보이는 곡 전체)을 한 창에서 한꺼번에 정리합니다. 제목(없으면 파일명)에서 `【MV】`, `(Official Music Video)`, `[4K]`, `(Lyrics)`, `(128kbit_AAC)` 같은 꼬리말을 떼고, `아티스트 - 제목`이면 아티스트 칸으로 옮깁니다. `曲名 / 歌手` 모양, 채널 이름(`… - Topic`, `…VEVO`)도 다듬습니다.
  - 옵션을 바꾸면 미리 보기가 바로 바뀝니다. 거꾸로 나뉜 줄은 골라서 **↔ 뒤바꾸기**(⌘R), 건드리지 않을 줄은 **빼기**(⌘D)한 뒤 **모두 적용**.
  - **더 지울 말 (정규식)**: 기본 꼬리말 말고 더 지울 것 (예: `\(Ateam Arrange\)|#\S+`). 대소문자 무시.
  - **나누기 정규식**: `(?<artist>…)`, `(?<title>…)` 이름 그룹으로 아티스트·제목을 직접 정합니다 (예: `^(?<title>.+?) ~ (?<artist>.+)$`). 맞는 곡은 기본 규칙보다 먼저, 맞지 않는 곡은 기본 규칙대로. 이름 없는 그룹 두 개면 '제목 모양' 순서로 봅니다.
  - 고른 옵션·정규식은 기억되고, 같은 설정을 액션 그룹의 'YouTube 제목 정리' 액션으로도 쓸 수 있습니다.
- **같은 곡 · 여러 버전 찾기** (편집 메뉴, ⇧⌘U): 목록에서 제목이 같은 곡을 묶어 보여 줍니다 (YouTube·JDownloader 꼬리말, 앞 번호는 빼고 비교). 묶음마다 음질이 가장 좋은 곡(★)을 남기고 나머지를 체크해 두며, 체크한 곡을 목록에서 고르거나 목록에서 뺍니다(파일은 그대로). 아티스트도 같아야 함, 길이 차이 몇 초 이내만 옵션. 더블클릭하면 재생합니다.
- **앨범 점검** (편집 메뉴, ⇧⌘L): 같은 앨범 이름의 곡들 사이에서 Apple Music 앨범을 갈라지게 하는 차이(앨범 이름 표기, 앨범 아티스트, 컴필레이션, 디스크·트랙 총수, 커버)와 연도·장르 차이를 찾습니다. 앨범 아티스트가 없고 곡마다 아티스트가 다른 경우도 알려 줍니다. 맞출 값을 골라 체크한 항목만 맞추고, 트랙 번호 겹침·빠짐은 알려 줍니다. 고른 곡이 있으면 그 곡이 속한 앨범 전체를, 없으면 목록 전체를 점검합니다.
- **목록 칸에서 바로 고치기**: 제목·아티스트·앨범·앨범 아티스트·연도·트랙·디스크·장르·작곡가·코멘트·파일명 칸을 **더블클릭**하거나 **F2**(macOS 는 Return 도). 파일명은 확장자를 뺀 이름만 고칩니다. 안전 저장·실행 취소·Music 반영이 그대로 따라옵니다. 고칠 수 없는 칸(길이·비트레이트 등)을 더블클릭하면 전처럼 재생합니다.
- **태그 비교** (편집 메뉴, ⇧⌘D, 또는 여러 곡 우클릭): 고른 곡(최대 8곡)의 음질·파일 정보·모든 필드·커버를 나란히 보여 주고 값이 다른 줄을 노란색으로 표시합니다. 다른 줄만 보기.
- **실행 취소** (⌘Z): 저장, 변환, 액션, 자동 번호, 태그 제거를 작업 단위로 되돌립니다. 이 프로그램이 편집하지 않는 필드까지 포함해 태그 전체, 파일 이름, 수정 시각을 원래대로 돌려놓습니다. 최근 30개 작업까지 기억하며, 앱을 끄면 기록이 사라집니다.
- **다시 실행** (⇧⌘Z, Windows 는 Ctrl+Y): 실행 취소한 작업을 다시 합니다 (도구 막대 **다시 실행**). 새 작업을 하면 다시 실행 기록은 비워집니다.
- **다른 곳에서 바뀐 곡 확인**: 실행 취소·다시 실행하기 전에, 저장한 뒤 Music 등 다른 곳에서 태그가 바뀐 곡이 있으면 어떤 곡의 무엇이 바뀌었는지 보여 주고 묻습니다 — 모두 되돌리기 / 바뀐 곡은 빼고 / 취소.

## 커버 짝짓기 (커버 → 커버 짝짓기…, ⇧⌘J)

곡마다 그림 파일을 직접 골라 커버로 넣습니다. JDownloader 등으로 받은 섬네일(`곡명 (BQ).jpg`)을 다른 곳에서 받은 고음질 곡에 넣을 때 씁니다.

- 왼쪽: LocalTag에서 선택한 곡(선택이 없으면 목록 전체) — 지금 커버 · 곡 · 새 커버 · 그림 파일
- 오른쪽: 그림 폴더 — **그림으로 보기**(섬네일) 또는 **제목으로 보기**(파일 이름만 한 줄씩)
- 그림을 곡 위로 끌어다 놓거나 더블클릭(제목 보기에서는 Return)하면 짝이 되고 다음 곡으로 넘어갑니다. 자동으로 짝짓지는 않습니다.
- **고른 곡과 이름이 비슷한 순**: 켜면 고른 곡과 이름이 비슷한 그림이 앞에 옵니다 (`(BQ)`, `(128kbit_AAC)`, `pitch 06` 같은 꼬리말은 빼고 비교). 끄면 폴더 이름순으로 고정됩니다.
- 크기(원본·500·600·1000), **중앙 자르기**(켜면 가운데를 정사각형으로 꽉 채움, 끄면 전체를 넣고 흰 여백), **검은 띠 빼기**. 새 커버 칸에는 이 옵션을 거친 결과가 보입니다.
- 적용하면 짝지은 곡에만 커버를 넣습니다 (안전 저장 · 백업 · 되돌리기 · Music 자동 반영).

## 앨범아트 추출 (커버 → 앨범아트 추출…, ⇧⌘X)

앨범아트 추출기 앱을 합친 기능입니다. 곡마다 앨범아트를 트랙 순서대로 `번호 곡명.jpg` 이미지 파일로 저장합니다 (저장 폴더 아래 `아티스트 - 앨범` 폴더).

- **미리 보기** (링크 · YouTube): 링크를 붙여 넣으면 곡·영상마다 그림을 작게 먼저 보여 줍니다(저장은 안 함). 그림을 누르면 체크/해제, 두 번 누르면 크게, 모두 고르기·모두 빼기 — **체크한 것만** 원래 크기로 받습니다. YouTube 는 자르기를 켜면 잘린 모양으로 미리 보입니다.
- **링크로 추출**: Apple Music 앨범·플레이리스트 링크. 크기 600·1000·1500·3000px, 중복 이미지 제외.
- **내 보관함**: Music 앱 보관함의 앨범을 골라 Music이 가진 앨범아트를 저장. 디스크가 여러 장이면 `1-01` 처럼 붙입니다.
- **목록의 곡**: LocalTag 목록에서 선택한 곡(선택이 없으면 목록 전체)의 파일 속 앨범아트를 앨범별로 저장.
- **YouTube**: 영상 하나 또는 재생목록 전체의 섬네일. 화질 선택, 위아래 검은 띠를 걷어낸 뒤 가운데 정사각형으로 자르기(300·500·720·1000).

저장 폴더는 앨범아트 추출기에서 쓰던 폴더를 그대로 이어 씁니다. 인터넷은 링크·YouTube 추출을 누를 때만 씁니다.

## 4단계 기능: 확장 태그, 내보내기, 재생목록

- **확장 태그** (편집 → 확장 태그…, ⌘T): 파일의 모든 필드를 보고 추가·수정·삭제합니다.
  - `LYRICIST`, `MOOD`, `BPM`, `UNSYNCEDLYRICS`(가사), `CATALOGNUMBER` 같은 사용자 정의 필드도 됩니다.
  - 형식마다 알맞은 저장 방식으로 씁니다. ID3는 전용 프레임 또는 TXXX, MP4는 전용 아톰 또는 iTunes 사용자 정의 필드, FLAC·OGG·APE·WMA는 필드 이름 그대로입니다.
  - 여러 커버를 관리합니다: 추가, 삭제, 내보내기, 종류(앞 표지, 뒷 표지 등)와 설명 지정
  - 여러 파일을 선택하면 값이 다른 필드는 `< 유지 >`로 표시되고, 바꾼 필드만 씁니다.
- 확장 필드는 포맷 문자열(`%lyricist%`), 변환기, 액션, 필터에서도 씁니다. 필드 선택칸에 이름을 직접 입력하면 됩니다.
- **내보내기** (⌘E): CSV(엑셀용, 한글 깨짐 방지), HTML(표 웹 페이지), 텍스트. 열과 줄은 포맷 문자열로 정합니다.
- **재생목록 만들기** (⌘L): 선택한 파일을 목록 순서대로 M3U8로 저장합니다. 상대 경로와 곡 정보(#EXTINF) 옵션이 있습니다.

## 5단계 기능: 앨범태그에서 옮겨 온 기능

- **안전 저장** (설정, 기본 켜짐): 원본에 바로 쓰지 않고 사본에 쓴 뒤 원본에 반영합니다. 원본에는 달라진 부분(태그)만 다시 씁니다 — 오디오 데이터(MP3 프레임, FLAC 프레임, M4A mdat)의 위치가 그대로면 원본의 오디오는 읽지도 쓰지도 않아 그대로 남고(그래서 빠름), 태그가 커져 오디오가 뒤로 밀리면 바이트 단위로 같은지 확인한 뒤 다시 씁니다. 파일 번호도 그대로라 Apple Music이 곡을 놓치지 않습니다. 같은 APFS 디스크에서는 사본을 복제본(clone)으로 만들어 큰 파일도 바로 끝납니다. 작업 중에 다른 프로그램이 파일을 바꿨으면 교체하지 않습니다. iCloud에서 아직 내려받지 않은 파일, 링크, 읽기 전용 파일은 건드리지 않습니다. Finder 태그 같은 확장 속성도 보존합니다.
- **원본 백업** (설정 → 백업…, ⇧⌘B): 저장하기 전 원본 파일을 통째로 보관합니다. 같은 APFS 디스크에서는 복제본으로 만들어, 실제로는 바뀐 부분만큼만 공간을 씁니다. 앱을 다시 켜도 작업 단위로 되돌릴 수 있습니다. 백업 이후 다시 바뀐 파일은 덮어쓰기 전에 물어봅니다. 보관 기간(기본 30일)과 최대 용량(기본 5GB)을 넘으면 오래된 것부터 지웁니다.
- **앨범아트** (커버 → 앨범아트 찾기 · 가져오기…, ⇧⌘A, 또는 패널의 '찾기…')
  - Apple Music 국가별 검색(실패하면 iTunes 검색으로 대체), 결과를 누르면 가장 큰 크기로 받기
  - YouTube 영상 주소로 썸네일 가져오기(정지 이미지만, 영상·음원은 받지 않음), Apple Music 앨범 주소, https 이미지 주소
  - 파일, 클립보드, 현재 커버, 최근에 가져온 이미지
  - 크기: 원본 / 500 / 600 / 1000, 맞춤: 중앙 자르기 / 비율 유지·검은 여백(기본) · 흰 여백 · 투명 여백(PNG), 가장자리 검은 띠 없애기
- **커버 크기 조정** (⇧⌘K, 액션 '커버 크기 조정'): 여러 파일의 커버를 파일마다 500×500 등으로 한꺼번에 바꿉니다.
- **Apple Music 연동** (Music 메뉴)
  - **Music 보관함 점검** (Music 메뉴): 보관함의 노래에서 커버 없는 곡, 이름이 같은데 여러 앨범으로 갈라져 보이는 앨범(어떤 차이로 갈렸는지 함께), 파일을 못 찾는 곡을 찾습니다. 고른 곡(앨범을 고르면 그 앨범 전부)을 LocalTag 목록으로 엽니다. 갈라진 앨범은 **열어서 앨범 점검으로 맞추기** 한 번으로 열고 앨범 점검(⇧⌘L)까지 띄우며, 맞춘 뒤에는 자동 반영이 꺼져 있어도 이번만 Music 에 반영해 앨범을 하나로 합칩니다. Music 에 명령을 보내지 않고 iTunesLibrary 로 읽기만 해서 Music 은 아무것도 바뀌지 않습니다 (2300곡 1초).
  - Apple Music에 반영 (⇧⌘M): 선택한 곡만 Music에서 새로 읽게 합니다. Music이 파일을 옮겼으면 목록의 경로도 다시 연결합니다.
  - 저장한 뒤 자동으로 Music에 반영 (켜고 끌 수 있음)
  - 커버를 바꾼 곡은 반영한 뒤 Music 이 화면에 쓰는 커버가 파일과 같은지 확인하고, 다르면 Music 에 다시 지정합니다 (Music 이 같은 앨범의 다른 곡 그림을 붙들고 있어 곡 정보에 커버가 비어 보이는 경우).
  - **반영한 뒤 Music 다시 켜기** (하지 않기(기본) · 재생 중이 아닐 때만 · 항상): 앨범·앨범 아티스트·컴필레이션·디스크를 바꿔 반영하면 Music 보관함 데이터는 맞는데 앨범 화면에서 곡이 갈라져 보일 때가 있습니다. 반영이 끝나면 Music 을 뒤에서 종료했다가 다시 켜 화면을 정리합니다. '항상'은 듣던 곡과 위치를 기억했다가 이어서 재생합니다. 되돌리기(⌘Z)·직접 'Music에 반영'에도 적용됩니다. 0.9.7 부터는 보통 필요 없지만, 그래도 앨범이 갈라져 보이면 켜 두세요.
  - 반영 속도 (몰아서 · 빠르게 · 보통 · 천천히, 기본 빠르게): **몰아서**는 곡마다 기다리지 않고 한꺼번에 새로 읽게 한 뒤, 끝나고 한 번에 확인해 아직 옛 정보인 곡만 다시 반영합니다 (가장 빠름). 나머지는 한 곡씩 Music이 새 정보와 파일 정리를 끝낼 때까지 기다린 뒤 다음 곡으로 넘어갑니다. 저장하기 전에 Music 곡을 제목·앨범으로 찾아 두고 저장 뒤에는 그 곡만 반영하므로, 빠르게 해도 앨범 화면이 갈라지지 않습니다.
  - Music에서 선택한 곡 추가 (⇧⌘I), Music의 곡·앨범을 LocalTag 창에 끌어다 놓기
  - Music 권한 확인 / 권한 설정 열기. Music과 함께 쓰려면 macOS 권한 두 가지가 필요합니다: 'Music 제어'(자동화)와 'Apple Music 보관함 접근'(미디어 및 Apple Music). 새 버전을 처음 켤 때 아직 받지 않은 권한을 한꺼번에 묻습니다 (서명하지 않은 앱이라 macOS가 버전마다 다시 묻습니다).
- **옮겨진 파일 다시 찾기**: 목록 새로 고침(F5) 때 사라진 파일을 같은 디스크에서 찾아 다시 연결합니다.

## 도구 막대 사용자화

설정 → **도구 막대 사용자화…** (또는 도구 막대 우클릭). Mac 터치 바·Finder 도구 막대 사용자화처럼 동작합니다.

- 단추 모음 창(기본 · 목록 · 재생 · 태그 고치기 · 변환 · 커버 · 점검 · 정리 · 액션 · 내보내기 · 백업 · Apple Music 으로 분류)에서 원하는 단추를 **실제 도구 막대 위로 끌어다 놓습니다** — 들어갈 자리에 세로선이 보입니다. 그냥 누르면 맨 끝에 들어갑니다.
- 도구 막대의 단추를 끌어 **순서를 바꾸고**, 도구 막대 **밖으로 끌어내면 빠집니다**.
- **구분선**, 뒤의 단추를 오른쪽 끝으로 미는 **늘어나는 공간**, 처음 배치로 돌리는 **기본 세트**도 끌어다 놓습니다.
- **완료**(또는 창 닫기)로 저장, **취소**로 원래대로. 사용자화하는 동안은 단추를 눌러도 기능이 돌지 않습니다.
